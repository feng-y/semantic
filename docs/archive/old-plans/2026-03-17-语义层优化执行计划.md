## 第1周：智能审查分类

### 目标
实现高置信度项目自动批准，低优先级项目自动延期。

### 流水线步骤

#### 步骤 1.1：设计分类逻辑（第1天）
**角色**: 建模工程师 + 领域专家

**任务：**
1. 定义置信度阈值
   - 高置信度：≥90%，优先级≥8.0 → 自动批准
   - 中置信度：60-90%，优先级5.0-8.0 → 需要审查
   - 低置信度：<60% 或 优先级<5.0 → 自动延期

2. 定义分类规则
   ```python
   if semantic_validity == 'pass' and confidence == 'high' and priority >= 8.0:
       return 'keep'  # 自动批准
   elif priority < 5.0:
       return 'backlog'  # 自动延期
   else:
       return 'verify_first'  # 人工审查
   ```

**交付物**: `docs/semantic-foundation/semantic/分类规则.md`

**验收标准：**
- [ ] 规则覆盖所有置信度级别
- [ ] 规则覆盖所有优先级范围
- [ ] 领域专家批准规则
- [ ] 边界情况已文档化

**协作方式：**

- 领域专家审查和验证
- 1小时同步会议对齐
