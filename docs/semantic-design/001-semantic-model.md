# 001 Semantic Model

## Analysis
Semantic construction needs a stable projection model for repository understanding.

## Research
Business-first models are fragile for infrastructure repositories.

## Questions
Should semantic projection be domain-first or system-first?

## Alternatives
- Business / System / Runtime
- Domain-first
- Intent / Structure / Behavior

## Scoring
Intent / Structure / Behavior is the most stable and general.

## Recommendation
Use Intent / Structure / Behavior as the core semantic model.

## Decision
Accepted.
