# 002 Command Model

## Analysis
The system needs one-time bootstrap and iterative refinement.

## Research
Engineering tools usually separate bootstrap from iterative workflows.

## Questions
Should review or synthesize be separate commands?

## Alternatives
- init + discover
- init + discover + refine
- init + discover + refine + synthesize

## Scoring
init + discover + refine is the most coherent v1 model.

## Recommendation
Use init / discover / refine.

## Decision
Accepted.
