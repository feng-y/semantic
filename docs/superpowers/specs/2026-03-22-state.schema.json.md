---

这版 `state.schema.json` 重点有 6 个：

### 1. `repo_snapshot` 单独挂顶层

因为整个 pipeline 都围绕当前 snapshot 运转：

* preflight 要比对它
* baseline 要冻结它
* resume 要检查它

### 2. `pipeline.resume_from_stage`

这是给 `/repo-structure resume` 用的，不需要自己猜。

### 3. `stages` 和 `artifacts` 分开

不要混在一起。

* `stages` 关心执行过程
* `artifacts` 关心输入输出状态

这对 debug 很重要。

### 4. `codebase_dossier` 明确列 7 个文件

这里就把你前面修正过的 7-file dossier 正式固化了。

### 5. `artifactState.status` 有 `optional_missing`

这样 `docs/ARCHITECTURE.md` 这种 optional input 可以被显式表达，而不是用 `missing` 混过去。

### 6. `warnings` / `issues` 都是数组

先保持轻量，够用就行。
后面真要升级，可以再换成结构化 issue object。
