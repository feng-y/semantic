## 🔴 P0 - 关键优先级（必须立即修复）

### Issue S1: Semantic 层 - 移除硬编码兜底，实现 fail fast

**来源**: Semantic 层 review
**影响**: 数据质量安全网
**风险**: 在非 CC 环境下产生垃圾数据

**问题描述**:
Python 脚本在 CC 输出不符合预期时，不应静默降级填入占位字符串，而应明确报错。

**涉及文件**:
1. `src/semantic/build_candidates.py` - 硬编码 'Repository Structure' 等
2. `src/semantic/apply_review.py` - 默认值 'backlog'
3. `src/semantic/finalize_assets.py` - 占位 summary
4. `src/semantic/extract_signals.py` - WARNING 而非 raise

**修复方案**:
```python
# 示例：build_candidates.py
def synthesize_domain_candidates(domain_signals: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    for signal in domain_signals:
        # 验证必需字段
        required_fields = ['name', 'summary', 'boundary']
        missing = [f for f in required_fields if f not in signal]

        if missing:
            raise ValueError(
                f"Signal missing required fields: {missing}. "
                f"This function expects data generated by Claude Code prompts. "
                f"Cannot synthesize candidates without LLM-generated content."
            )

        # 使用真实数据，不用硬编码兜底
        candidate = {
            'name': signal['name'],  # 从 CC
            'summary': signal['summary'],  # 从 CC
            ...
        }
```

**预计时间**: 2-3小时
- 修改 4 个文件
- 添加输入验证
- 更新相关测试
- 验证错误路径

**优先级理由**:
- 数据质量的最后一道防线
- 防止静默失败
- 明确失败优于默默返回无意义数据
